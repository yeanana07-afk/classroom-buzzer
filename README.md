# 🔔 먼저 도전! (수업용 버저)

선생님이 **시작**을 누르면 모든 학생 화면에 **3 · 2 · 1** 카운트가 나오고, 0이 되는 순간 **도전!** 버튼이 활성화됩니다.
누른 순서는 Firebase **서버 시각** 기준으로 정해져 선생님 화면에 1등부터 차례로 표시됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 첫 화면 (선생님 / 학생 선택) |
| `teacher.html`, `teacher.js` | 선생님 화면: 참가자 설정, 시작·마감·초기화, 도전 순서, 접속 현황, QR 코드 |
| `student.html`, `student.js` | 학생 화면: 방 코드 입력 → 이름/모둠 선택 → 도전 버튼 |
| `firebase.js` | Firebase 설정값과 공통 함수 (**여기에 내 설정값 입력**) |
| `database.rules.json` | Realtime Database 보안 규칙 (카운트 전/마감 후/중복 도전 차단) |
| `style.css` | 디자인 |

## 1. Firebase 준비 (처음 한 번)

1. <https://console.firebase.google.com> 에서 **프로젝트 추가**
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: `asia-southeast1 (싱가포르)` 권장 / **잠금 모드**로 시작
3. **규칙** 탭에 `database.rules.json` 내용을 그대로 붙여넣고 **게시**
4. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(</>)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을
   `firebase.js` 맨 위에 붙여넣기 (`databaseURL`이 꼭 들어 있어야 합니다)

## 2. 인터넷에 올리기 (학생들이 접속할 주소 만들기)

ES 모듈을 사용하므로 파일을 더블클릭(`file://`)으로 열면 동작하지 않습니다. 아래 중 하나로 올려 주세요.

- **Firebase Hosting** (추천)
  ```bash
  npm install -g firebase-tools
  firebase login
  firebase init hosting     # public 폴더를 이 폴더(.)로, SPA 질문은 No
  firebase deploy
  ```
- **GitHub Pages / Netlify** 등 정적 호스팅에 폴더째 업로드
- 컴퓨터에서 테스트만 할 때: 이 폴더에서 `npx serve` 또는 `python3 -m http.server` 후 `http://localhost:...` 접속

## 3. 수업에서 사용하기

1. 선생님: `teacher.html` 열기 → 방 코드(4자리)가 자동으로 만들어짐
2. 오른쪽 **참가 방식 설정**에서 **개인별**(이름 목록) 또는 **모둠별**(모둠 수) 입력 → **설정 저장**
3. 학생: QR 코드를 찍거나 주소로 접속 → 방 코드 확인 → 자기 이름(모둠) 선택 → **입장하기**
   - 참가자 칸이 초록색이면 접속한 상태입니다.
4. 선생님: **▶ 시작** → 학생 화면에 3·2·1 → 0이 되면 버튼 활성화
5. 누른 순서대로 선생님 화면에 🥇 1등부터 표시 (시작 후 몇 초 만에 눌렀는지도 표시)
6. 다음 문제는 다시 **▶ 시작** (이전 기록은 자동으로 지워짐). 더 이상 받지 않으려면 **⏹ 마감**

### 동작 규칙
- 카운트가 끝나기 전에는 버튼이 눌리지 않으며, 서버 규칙에서도 한 번 더 막습니다.
- 한 사람(모둠)은 한 라운드에 **한 번만** 도전할 수 있습니다. 모둠별일 때는 모둠원 중 가장 먼저 누른 기록 하나만 남습니다.
- 학생 화면은 새로고침해도 이전에 고른 이름으로 다시 입장합니다. 키보드 **스페이스바**로도 누를 수 있습니다.
- 선생님 화면을 새로고침해도 같은 방 코드를 유지합니다. 다른 반 수업 때는 **새 방 만들기**를 누르세요.

## 참고 / 한계
- 로그인(인증) 없이 동작하는 간단한 구조라서, 방 코드와 주소를 아는 사람은 누구나 접속할 수 있습니다. 수업용으로는 충분하지만, 장난이 걱정되면 Firebase Authentication을 추가해 선생님만 `config`·`round`를 쓰게 규칙을 강화할 수 있습니다.
- Firebase 무료(Spark) 요금제의 동시 접속 한도는 100명이라 한 학급 수업에는 넉넉합니다.
- 순서는 각 학생의 클릭이 **Firebase 서버에 도착한 시각**으로 정합니다. 와이파이 상태가 크게 다르면 수십 ms 정도 차이가 날 수 있습니다.
